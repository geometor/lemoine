Problem XVII: Parallel Through an External Point — Summary¶

Executive Summary & Complexity Metrics (Prob. XVII, pp. 9–10, fols. 0025–0026)

  • Scope: Problem XVII — Parallel through an external point (fols. 0025–0026, pp. 9–10).

  • Efficiency Trade-Off: Both constructions by Gaston Tarry tie at \(S = 9\) (down from classical \(S = 11\), XVII — Parallel Through an External Point to a Given Line), illustrating the subtle duality between fewer circles (1st method: 2 circles, \(E = 6\)) and superior alignment precision (2nd rhombus method: 3 circles, \(E = 5\)).

  • Minimal-Instrument Bridge: Un-traced variant matches Mascheroni Libro IV § 80 (\(5C_1 + 2C_3\) for point \(D\)), contrasting with Steiner’s First Problem (\(11R_1 + 6R_2\) by pure straightedge via fixed circle \(M\)).
