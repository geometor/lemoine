Applications I–VII : Droites, cercles et prise de longueur¶

Émile Lemoine — La Géométrographie (Texte français de référence, p. 5, fols. 0021)

À la suite immédiate de l’Exposition, Lemoine fixe les sept premières applications élémentaires qui servent d’atomes opératoires à tout le mémoire :

  • I. Tracer une droite quelconque : \(\mathrm{op.} : (R_2)\) ; \(S = 1, E = 0\) ; 1 droite.

  • II. Tracer une droite passant par un point donné \(A\) : \(\mathrm{op.} : (R_1 + R_2)\) ; \(S = 2, E = 1\) ; 1 droite.

  • III. Tracer la droite qui joint deux points donnés \(A\) et \(B\) : \(\mathrm{op.} : (2R_1 + R_2)\) ; \(S = 3, E = 2\) ; 1 droite.

  • IV. Tracer un cercle quelconque (centre et rayon arbitraires) : \(\mathrm{op.} : (C_3)\) ; \(S = 1, E = 0\) ; 1 cercle.

  • V. Tracer un cercle de rayon quelconque ayant un centre donné \(O\) (ou passant par un point donné \(A\) avec un centre quelconque) : \(\mathrm{op.} : (C_1 + C_3)\) ; \(S = 2, E = 1\) ; 1 cercle.

  • VI. Prendre entre les pointes du compas une longueur donnée \(AB\) : \(\mathrm{op.} : (2C_1)\) ; \(S = 2, E = 2\) ; 0 cercle.

  • VII. Porter sur une droite tracée une longueur déjà prise entre les pointes du compas : à partir d’un point indéterminé de la droite, \(\mathrm{op.} : (C_2 + C_3)\) ; à partir d’un point déterminé de cette droite, \(\mathrm{op.} : (C_1 + C_3)\) ; dans les deux cas, \(S = 2, E = 1\), 1 cercle.

L’application V mérite une attention particulière : poser une pointe en un point déterminé \(A\) et laisser la seconde pointe tomber en un point quelconque du plan (opération de coût nul) pour tracer un cercle passant par \(A\) ne coûte que \(C_1 + C_3\). Ce seul geste fonde la simplification de la parallèle de Gaston Tarry (Problème XVII) et de la perpendiculaire élevée par le cercle de Thalès (Problème XX).
