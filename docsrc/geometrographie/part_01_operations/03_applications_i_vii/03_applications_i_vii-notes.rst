* **Scan Verification Correction**: Direct inspection of folio ``0021`` (p. 5) confirms that Application **VI** in the 1893 Pau memoir is specifically *taking a given length* :math:`AB` (:math:`2C_1`), and Application **VII** is *laying off an already captured length* (:math:`C_2 + C_3` or :math:`C_1 + C_3`), distinct from Application **VIII** (fol. ``0022``, p. 6) which combines both acts (:math:`2C_1 + C_2 + C_3` or :math:`3C_1 + C_3`).
* **Concordance Cross-Reference**: Application III corresponds to Euclid I.Post.1 (`G.1` in :external+elements:doc:`index`) and :ref:`concordance-line-two-points`.
